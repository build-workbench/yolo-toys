# 社区

欢迎来到 YOLO-Toys 社区！我们正在共同构建一个多模型视觉推理平台。

## 参与方式

### 讨论渠道

| 平台 | 用途 |
|------|------|
| [GitHub Discussions](https://github.com/your-org/yolo-toys/discussions) | 问答、想法、展示分享 |
| [GitHub Issues](https://github.com/your-org/yolo-toys/issues) | 错误报告、功能请求 |
| [Discord](https://discord.gg/yolo-toys) | 实时聊天、社区通话 |

### 社区准则

1. **保持尊重** - 友善对待每个人
2. **建设性** - 关注解决方案，而非问题
3. **耐心** - 维护者是志愿者
4. **乐于助人** - 在力所能及时回答问题

### 错误报告

通过 [GitHub Issues](https://github.com/your-org/yolo-toys/issues) 报告错误：

```markdown
**描述**
清晰的错误描述。

**复现步骤**
复现步骤：
1. 运行 `docker run ...`
2. 发送请求到 `/infer`
3. 看到错误

**预期行为**
你期望发生什么。

**环境**
- 操作系统：Ubuntu 22.04
- Docker：24.0
- GPU：NVIDIA T4
```

## 行为准则

### 我们的承诺

我们承诺让参与我们的社区成为每个人都没有骚扰的体验，无论年龄、体型、残疾、种族、性别认同和表达、经验水平、教育程度、社会经济地位、国籍、个人外貌、种族、宗教或性认同和取向。

### 我们的标准

**正面行为：**
- 使用热情和包容的语言
- 尊重不同的观点
- 优雅地接受建设性批评
- 关注对社区最有利的事
- 对其他社区成员表示同理心

**不可接受的行为：**
- 捣乱、侮辱性评论和人身攻击
- 公开或私下骚扰
- 未经许可发布他人的私人信息
- 其他可能被合理认为不当的行为
