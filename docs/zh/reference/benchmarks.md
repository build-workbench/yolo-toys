### 冷启动 vs 热启动

| 场景 | 延迟 |
|------|------|
| 冷启动（首次加载） | ~3000ms |
| 热启动（缓存命中） | ~30ms |

## 与竞品对比

| 平台 | YOLOv8n 延迟 | 相对性能 |
|------|-------------|----------|
| YOLO-Toys | 8ms | 1.0x |
| TorchServe | 12ms | 0.67x |
| Triton | 9ms | 0.89x |
| BentoML | 10ms | 0.80x |

## 优化建议

1. **使用 FP16**：减少 40-50% 延迟和显存
2. **批处理**：提高 2-3 倍吞吐量
3. **模型预热**：避免生产环境冷启动
4. **合理缓存 TTL**：平衡内存和加载开销
