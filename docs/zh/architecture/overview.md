# 架构概述

高层系统设计与组件交互。

## 系统组件

### 1. API 层

API 层提供两个接口：

- **REST API** — 用于单图推理的 HTTP 端点
- **WebSocket** — 用于视频分析的实时流

### 2. Handler 管理器

负责：
- 模型生命周期管理
- 动态模型加载/卸载
- 资源分配

### 3. Handlers

每种模型类型有其自己的 Handler：
- 封装模型特定逻辑
- 实现标准接口
- 管理模型资源

## 请求流程

```
1. 客户端请求
        │
        ▼
2. API 路由
        │
        ▼
3. Handler 管理器
        │
        ▼
4. 模型 Handler
        │
        ▼
5. 推理引擎
        │
        ▼
6. 响应
```

## 设计原则

- **单一职责** — 每个 Handler 专注做好一件事
- **开闭原则** — 添加模型无需修改现有代码
- **依赖倒置** — 依赖 Handler 抽象而非具体实现
