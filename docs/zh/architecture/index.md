# 架构

了解 YOLO-Toys 系统设计和组件。

## 概述

YOLO-Toys 使用模块化的 Handler 架构，支持：

- **模型隔离** — 每个模型在其自己的 Handler 中运行
- **易于扩展** — 通过实现 Handler 接口添加新模型
- **统一 API** — 所有模型类型使用单一接口
