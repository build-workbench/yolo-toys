# YOLO-Toys

Multi-model vision inference service with unified FastAPI + WebSocket interface.

```bash
# Docker
docker run -p 8000:8000 ghcr.io/lessup/yolo-toys:latest

# Detection
curl -X POST "http://localhost:8000/detect" \
  -F "file=@image.jpg" \
  -F "model=yolov8n"

# WebSocket streaming
python -c "
import asyncio, websockets, json
async def stream():
    async with websockets.connect('ws://localhost:8000/ws/detect') as ws:
        await ws.send(json.dumps({'model': 'yolov8n'}))
        # Send image and receive results
asyncio.run(stream())
"
```
