## 🧩 设计模式

### 1. 策略模式（Handler 系统）

所有模型类型实现统一接口：

```python
class BaseHandler(ABC):
    @abstractmethod
    def load(self, model_id: str) -> tuple[Any, Any | None]:
        """加载模型和处理器"""
        pass

    @abstractmethod
    def infer(self, model, processor, image, **params) -> dict:
        """运行推理并返回格式化结果"""
        pass
```

### 2. 注册表模式

集中式模型注册和查找：

```python
MODEL_REGISTRY = {
    "yolov8n.pt": {
        "category": ModelCategory.YOLO_DETECT,
        "name": "YOLOv8 Nano",
        "task": "detect"
    }
}
```

## 📦 组件详情

| 组件 | 职责 |
|-----------|----------------|
| ModelManager | 模型生命周期、缓存、并发控制 |
| HandlerRegistry | 模型类别解析、Handler 实例化 |
| Handlers | 模型特定的加载和推理逻辑 |
